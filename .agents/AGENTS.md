# Regras do Projeto / Project Rules

## Controle de Branches e Merges
- **[CRÍTICO] Autorização para Branches Principais**: Qualquer alteração, checkout, commit direto ou merge nas branches `develop` e `main` **exige autorização prévia e explícita do usuário**. 
- Todas as implementações devem ser realizadas e mantidas em branches de funcionalidade (ex: `feature/*`).
- O agente nunca deve tentar fazer merge automático ou alternar para as branches `develop` ou `main` sem que o usuário tenha dado o comando ou permissão específica no chat.
